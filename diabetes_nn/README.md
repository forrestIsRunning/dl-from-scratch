# 多层神经网络 - 糖尿病预测

基于课件7-15/19实现的多层神经网络，用于糖尿病二分类预测。

## 网络结构

```
维度变换链: 8 → 6 → 4 → 1

输入层 (8维) ──→ 隐藏层1 (6维) ──→ 隐藏层2 (4维) ──→ 输出层 (1维)
     │               │                 │                │
   特征          Sigmoid           Sigmoid          Sigmoid
```

## 维度变换原理

每一层通过 `nn.Linear(in, out)` 实现维度变换，本质是矩阵乘法：

```
Linear(8, 6): [N,8] × [8,6] = [N,6]  (权重W1形状: [6,8])
Linear(6, 4): [N,6] × [6,4] = [N,4]  (权重W2形状: [4,6])
Linear(4, 1): [N,4] × [4,1] = [N,1]  (权重W3形状: [1,4])
```

## 为什么要逐层降维？

1. **非线性拟合能力**: 多层 + Sigmoid激活，能拟合复杂的非线性关系
2. **特征抽象**: 逐层提取高维抽象特征，比直接8→1的简单逻辑回归更精准

## 关键点

- **维度衔接**: 下一层的 `in_features` = 上一层的 `out_features`
- **激活函数**: Sigmoid 只改值、不改维度 (element-wise 操作)
